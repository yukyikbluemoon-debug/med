# ตารางยา

เว็บแอปส่วนตัวสำหรับดูตารางกินยาบนมือถือ เพิ่ม/แก้ไข/ลบยา ใส่รูปจากกล้องหรือแกลเลอรี และแจ้งเตือนผ่าน Telegram ตามเวลาที่ตั้งไว้

## ใช้งานในเครื่อง

```bash
node server.js
```

แล้วเปิด `http://localhost:5173`

ถ้าเอาขึ้น GitHub Pages สามารถใช้ `index.html`, `app.js`, `src/styles.css` ได้โดยตรง ไม่ต้อง build

## Google Drive / Google Sheets

ข้อมูลหลักเก็บใน Google Sheets และรูปยาเก็บใน Google Drive ผ่าน Google Apps Script

1. สร้าง Google Sheet ใหม่
2. ไปที่ Extensions > Apps Script
3. วางโค้ดจาก `apps-script/Code.gs`
4. Deploy เป็น Web app
5. ตั้งค่าให้รันเป็นบัญชีของคุณ และให้ผู้เข้าถึงเป็นเฉพาะตัวคุณหรือ Anyone with the link ตามรูปแบบที่ต้องใช้
6. นำ Web app URL มาใส่ในหน้า `ตั้งค่า` ของแอป

## Telegram

1. สร้างบอทผ่าน BotFather
2. นำ Bot Token มาใส่ในหน้า `ตั้งค่า`
3. หา Chat ID ของคุณ แล้วใส่ในหน้า `ตั้งค่า`
4. กดบันทึกตั้งค่า ระบบ Apps Script จะสร้างตัวตรวจแจ้งเตือนทุก 5 นาที

## รูปยา

ในฟอร์มเพิ่ม/แก้ไขยา มีปุ่ม `ถ่ายรูป` และ `เลือกรูป` รูปจะถูกย่อใน browser ก่อนบันทึก เพื่อให้ไฟล์เล็กลงและโหลดเร็วขึ้น
